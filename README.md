**基础信息**\
平台:Windows11\
C 语言环境:mingw64\
第三方库:SDL\

**游戏方式**\
进入游戏主界面,点击"开始游戏"后,会进入游戏规则界面;点击"退出游戏"则会退出游戏\
在游戏过程中会在左上角记录得分与最高纪录\
若获得分数,会在人物上方显示所得分数\
右上角记录着人物所拥有的道具数量\
在游戏规则界面按下"1"进入游戏\
若游戏失败,会弹出end界面,end界面中会显示本次游戏得分与历史最高得分,点击"再玩一局"则可以\
重新开始一局游戏;点击"退出游戏"会退出游戏\
一共有三种平台,一种道具,具体规则见下图\
![游戏规则说明](src/ryle3.png)\
随着分数的增加生成的平台会逐渐变小\
蓄力时通过小人压缩展示当前蓄力的进度(蓄力有上限,到达上限后无论按多久空格都只会跳到上限处)\
游戏中有bgm，且在蓄力,跳跃,得到分数,失败时会分别播放特定音效\
可以得到高分的(流氓)自动游戏功能:按下"0"可以自动往前跳并正确落到平台上,次数不限,所以只要不断地按"0"就可以轻松获得高分咯
